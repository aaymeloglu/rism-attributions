Conti, Francesco Bartolomeo (1681c-1732)

Same music

Two incipits match keyboard arrangements of the overture to Conti's Clotilde (1706): the Ouverture opening, and the 12/8 movement matches the Jigg (1001284369 incipit 1.1.1), which that record calls the third part of the same overture. The comparator notes that Handel also used this overture for the pasticcio Ormisda.
